# Сайт для продажи товаров

Этот проект предназначен для автоматизации работы магазина на маркетплейсах Ozon и Яндекс Маркет. Система синхронизирует остатки и цены товаров, получая данные от внешнего поставщика часов фирмы `casio`.
Проект разбит на 2 файла:
- `market.py` - содержит логику для работы с API Яндекс Маркета. Скрипт обновляет данные о наличии товаров и их стоимости.
- `seller.py` - содержит логику для работы с API Ozon. В нем также описаны общие функции: скачивание файла остатков от поставщика, очистка цен и деление больших списков на части.
